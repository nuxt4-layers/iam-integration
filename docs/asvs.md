# OWASP ASVS Mapping

How the suite meets the [OWASP Application Security Verification Standard 5.0](https://owasp.org/www-project-application-security-verification-standard/), chapter by chapter, and which member's controls carry each one. The target is **Level 2** for every member, with Level 3 where a chapter names it below. Each member's threat model holds the control register that the evidence column points to; this page says where the suite as a whole stands and what is left to the host.

This mapping is by chapter. A requirement-by-requirement verification is a separate audit, recorded here when it is done.

| Status | Meaning |
|---|---|
| Met | The members' controls cover the chapter at the target level, with tests named in their threat models |
| Host | The chapter is the host's to meet; the members do not hinder it |
| Shared | The members meet their part; the host must meet the rest, listed |
| Not applicable | The suite has no such feature |
